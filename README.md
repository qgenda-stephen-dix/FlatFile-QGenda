# qgenda

This is a standalone Flatfile demo exported from the Flatfile Demos monorepo.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set up your environment variables:
   - Copy the `.env.example` file to `.env`
   - Fill in your Flatfile credentials and configuration

3. Run the demo in development mode:
   ```bash
   npm run dev
   ```

4. Deploy to Flatfile:
   ```bash
   npm run deploy
   ```

## Available Scripts

- `npm run dev` - Start development mode
- `npm run deploy` - Deploy to Flatfile platform

## Directory Structure

- `src/` - Demo source code
- `support/` - Utility functions and helpers
